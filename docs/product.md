# 产品说明

简体中文 · [English](product_EN.md) · [README](../README.md)

## 概述

`miocli` 是面向单个 Mihomo 实例的终端控制面板。它通过键盘交互查看代理状态并执行明确的控制操作，适用于本地终端和 SSH 会话。

## 功能

- 浏览代理组、嵌套组及组成员；搜索组或当前成员。
- 切换 `Selector` 组中的节点，并通过 API 读回结果。
- 按协议或来源筛选节点，按 API 顺序、名称或延迟排序；测试节点或当前组的直接成员。
- 切换 Rule、Global、Direct 模式；查看并手动更新 proxy-providers。
- 为本次启动的托管内核管理完整配置档案，包括本地 YAML 和 HTTPS 来源。
- 查看当前连接的活跃路由摘要及连接、实例和诊断状态。

界面包含 Subscriptions、Groups、Nodes、Status 四个英文导航项。Nodes 是独立的全局节点列表；Subscriptions 中的完整配置档案与 Mihomo API providers 是两类不同资源。

## 操作与安全边界

- 仅管理一个 Mihomo controller。连接已有实例时不取得进程所有权，也不写入其配置。
- 只有 `Selector` 组允许切换成员；操作后通过 API 读取状态确认。延迟测试和模式变更结果也会显示 API 错误或未确认状态。
- `doctor` 只读检查配置与 API；`dev` 只连接已有内核。
- 托管模式须在 setup 中明确选择。配置写操作仅对本次启动的托管子进程开放；退出时只停止 miocli 启动的子进程。
- 不支持自动更新订阅、合并档案、覆写规则、分组结构编辑、多实例、实时流量图、日志查看或关闭单个连接。

写请求超时不自动重放。无法读回状态时，界面保留最后一次成功读取的数据并显示错误，不将未确认操作报告为成功。

## 首次安装与下载

安装器和缺失内核的下载优先 GitHub，网络/HTTP 失败时自动回退项目公开镜像。脚本本身也提供镜像下载入口，见 [README](../README.md)。已解析的版本不会因回退而变化；非法元数据、校验失败或取消立即停止，不替换已有程序。

Mihomo 随 miocli 固定经过验证的版本，下载后与内置 SHA-256 校验；不再查询上游 latest。已有内核优先复用，连接失败不自动下载内核。首版不新增离线安装或完整捆绑包，也不代理订阅、providers、规则集或 Geo 数据下载。
